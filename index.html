TUJUAN PEMBELAJARAN & MAP MISI

Selesaikan seluruh quest di bawah ini untuk menjadi Master Hardware Komputer!

01
Mission I

Hardware Explorer

  • Siswa mampu memahami definisi dasar dan konsep fisik hardware komputer.
  • Siswa mampu mengelompokkan komponen hardware berdasarkan kategori fungsinya.
02
Mission II

Input Device Mission

  • Mengidentifikasi perangkat input (Keyboard, Mouse, Scanner, Webcam, Mic).
  • Menjelaskan mekanisme bagaimana instruksi luar dimasukkan ke sistem komputer.
03
Mission III

Processing Core Mission

  • Menjelaskan fungsi CPU, GPU, Motherboard, dan RAM dalam mengolah perintah data.
  • Menganalisis hubungan interaksi antar-perangkat pemrosesan utama.
04
Mission IV

Output & Storage Mission

  • Memahami media penyimpanan data (HDD, SSD, Flashdisk) & perangkat luaran (Monitor, Printer).
  • Membedakan penyimpanan volatil (RAM) dan non-volatil (Storage).

The Lost Core — Akademi Teknologi Informatika

DEVELOPER / PENGEMBANG SATRIAJI

Sasaran Pengguna

Dirancang khusus untuk siswa Sekolah Menengah Pertama (SMP) Kelas 7, 8, dan 9 untuk menguasai konsep dasar hardware komputer secara menyenangkan.

Konsep Gamifikasi

Menggabungkan atmosfer visual MMORPG Futuristic Medieval dengan battle quiz dan arena puzzle interaktif untuk meningkatkan keterlibatan siswa.

Platform & Aksesibilitas

Aplikasi berbasis Single Page Web (HTML5/JS/Tailwind CSS), responsif di smartphone, tablet, maupun laptop tanpa perlu database/server tambahan.

Petunjuk Penggunaan Aplikasi

  1. Pilih faksi pahlawan (Sylvan, Bellator, atau Accretia) di halaman **Home** sebagai identitas tokomu.
  2. Pelajari tujuan & peta capaian misi di halaman **Misi**.
  3. Buka menu **Materi** untuk membaca ensiklopedia komponen hardware beserta contohnya dalam kehidupan sehari-hari.
  4. Uji pemahamanmu pada **Battle Quiz** untuk mendapatkan skor dan predikat gelar Hero.
  5. Selesaikan tantangan di **Arena Puzzle** dengan mencocokkan nama perangkat ke slot fungsi yang tepat.
